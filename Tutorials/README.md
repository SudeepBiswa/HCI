Tutorial:
https://realpython.com/python-speech-recognition/

The tutorial was used to learn the basics of the Python SpeechRecognition
library. In particular, I learned how to:

- Create a speech recognizer
- Access microphone input
- Adjust for background noise
- Record spoken audio
- Convert speech into text using Google Speech Recognition
- Handle errors when speech cannot be understood

The tutorial code was completed separately from the main HCI project. The
concepts learned from this tutorial were later applied to the
Voice-Controlled Desktop Navigation System.
